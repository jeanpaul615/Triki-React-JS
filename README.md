

# Triki-React-JS

Triki-React-JS es un juego clásico de tres en raya (tic-tac-toe) desarrollado con React y Vite. Este proyecto demuestra cómo construir una aplicación interactiva y rápida utilizando tecnologías modernas de JavaScript.

## Características

- Juego de tres en raya clásico, ideal para dos jugadores.
- Interfaz de usuario responsiva y atractiva.
- Implementación basada en React y Vite para un desarrollo rápido.
- Código modular y mantenible, siguiendo las mejores prácticas de React.

## Tecnologías utilizadas

Este proyecto utiliza las siguientes tecnologías:

- **React**: Una biblioteca de JavaScript para construir interfaces de usuario.
- **Vite**: Herramienta de desarrollo rápida para aplicaciones web modernas.
- **CSS**: Para el diseño y estilo de la interfaz.
- **JavaScript**: Lenguaje principal del proyecto.

## Instalación

Sigue estos pasos para instalar y ejecutar el proyecto en tu máquina local:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/jeanpaul615/Triki-React-JS.git
   ```

2. Accede al directorio del proyecto:
   ```bash
   cd Triki-React-JS
   ```

3. Instala las dependencias:
   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

5. Abre tu navegador en [http://localhost:5173](http://localhost:5173) para ver el proyecto en acción.

## Cómo jugar

1. Abre el juego en tu navegador.
2. Dos jugadores se turnan para seleccionar una casilla del tablero.
3. El primer jugador que coloque tres de sus marcas en una fila (horizontal, vertical o diagonal) gana la partida.
4. Si todas las casillas están llenas y ningún jugador ha ganado, el juego termina en empate.
